# 💱 Currency Converter

A simple and responsive Currency Converter built using **HTML, CSS, and JavaScript**. It allows users to convert one currency into another using real-time exchange rates fetched from an external API.

## 🚀 Features

- Convert between multiple currencies.
- Fetch exchange rates using a currency API.
- Dynamic country flags based on selected currencies.
- Default conversion from USD to INR.
- User-friendly interface.
- Automatic exchange rate calculation.
- Input validation and error handling.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- DOM Manipulation
- Currency Exchange API
- Flags API

## ⚙️ How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Ankit5960/currency-converter.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser or use the VS Code Live Server extension.
